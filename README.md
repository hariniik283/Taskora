# 📝 Taskora – Task Management Web App

**Taskora** is a modern and user-friendly task management web application designed to help users organize, track, and manage their daily tasks efficiently.

The application provides a clean and responsive interface with useful productivity features such as task categorization, due dates, reminders, drag-and-drop reordering, and dark mode.

## ✨ Features

* ✅ Create, edit, and delete tasks
* 📂 Organize tasks into categories
* 🔍 Filter tasks easily
* 📅 Set due dates
* 🔔 Task reminders
* 🖱️ Drag-and-drop task reordering
* 🌙 Dark mode
* ✨ Smooth animations and interactive UI
* 💾 Local Storage for persistent task data
* 📱 Responsive design
* 🚀 Live deployment

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage API
* Drag and Drop API
* Responsive Web Design

## 🎯 Project Objective

The main objective of Taskora is to provide a simple and efficient digital solution for managing daily activities, deadlines, and priorities without requiring a complex setup.
